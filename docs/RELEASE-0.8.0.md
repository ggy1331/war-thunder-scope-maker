# 0.8.0 pre-alpha

- Перемещение сцены: пробел + левая кнопка мыши или средняя кнопка. Shift + колесо — горизонтально, Alt + колесо — вертикально. Home или «В центр» возвращает сцену в центр. Обычное колесо по-прежнему меняет масштаб.
- Фон, сетка, рисование, выделение и ластик используют общее смещение сцены. Перемещение не меняет проект или экспортируемый прицел.
- Новые проекты и экспортируемые BLK получают имена scope_1, scope_2 и далее по максимальному номеру в выбранной исходной папке. Имя можно изменить в диалоге. Сохранение существующего проекта использует его прежнее имя. Если вручную сменить папку в диалоге, предложенное имя остаётся прежним; Windows запрашивает подтверждение перезаписи существующего файла.
- Установщик WT-Scope-Maker-Setup-0.8.0.exe устанавливает приложение в %LOCALAPPDATA%\Programs\WT Scope Maker без прав администратора и создаёт ярлыки на рабочем столе и в меню «Пуск».
- Для обновления закройте приложение и запустите новый установщик. Настройки, пользовательские проекты и посторонние файлы сохраняются. Автоматической загрузки обновлений пока нет.
- При переходе с portable-версии настройки можно перенести, скопировав settings.json рядом с установленным EXE при закрытой программе. Portable-версия остаётся доступна в ZIP.

Сборка установщика: powershell -ExecutionPolicy Bypass -File .\build-installer.ps1
