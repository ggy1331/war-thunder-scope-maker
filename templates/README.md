# Штатные сетки из локального War Thunder

`game/manifest.json` перечисляет 66 сеток из `config/tanksights.blk` установленного клиента 2.59.0.86: 62 общие и четыре для конкретных машин. Это реальные данные игры, преобразованные из бинарного BLK в текстовый.

Сетки появляются в списке шаблонов программы с префиксом **WT ·**. Выберите нужную и нажмите **Применить шаблон**. Исходные баллистические блоки и ограничения техники сохраняются. Предпросмотр показывает поддерживаемую геометрию, стандартные центральные линии, локальную толщину и текст; игровые автоматические шкалы и радиальное движение не эмулируются полностью.

Пресеты оформления `tankSightPresets` не являются геометрией и в библиотеку не включены. Источники, контрольная сумма контейнера и ограничения описаны в `docs/WAR_THUNDER_FORMAT.md` исходного проекта.
