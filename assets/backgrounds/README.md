# Фоны штатного редактора War Thunder

Извлечены из установленного клиента 2.59.0.86, без изменения исходных файлов игры.

- Контейнер: `E:\SteamLibrary\steamapps\common\War Thunder\ui\images.vromfs.bin`.
- SHA-256 контейнера: `94b05159d6f2fed54a6042ece9806cd8ce2851eb248300624604a11b9438625f`.
- Внутренние пути: `images/sight_menu_bg/tank_sight_preview_{1..4}_{day,night,nightvision,thermal}.avif`.
- Выбор четырёх сцен подтверждён игровым скриптом `gui.vromfs.bin/reactivegui/tanksightpreview.nut`: `BG_IMAGES_COUNT = 4`.
- В той же папке есть изображения с префиксом `tank_sight_preview_sm_`; они используются как миниатюры.

Все 16 полноразмерных изображений конвертированы из AVIF в PNG **без изменения разрешения 3840×2160 и декодированных RGB-пикселей**. PNG нужен для загрузки через стандартный Windows GDI+, без дополнительных кодеков. Исходные AVIF и другие ресурсы игры в билд не включены.

`manifest.json` содержит соответствие сцены, режима, файлов и контрольные суммы исходных AVIF. Скрипт подготовки: `tools/prepare-backgrounds.py` в исходном проекте. Он проверяет равенство каждого пикселя после преобразования. Генеративные инструменты, перерисовка и повышение резкости не применялись.

В программе фоны выбираются через кнопку «Фон…». Изображение вписывается полностью с сохранением пропорций. Затемнение по умолчанию выключено. Выбор встроенного фона сохраняется в `.wtsm` по ключу, а не по абсолютному пути. Собственный фон сохраняется ссылкой на файл; если файл переместить, его потребуется выбрать заново. Изображения не включаются в экспорт `.blk`.
