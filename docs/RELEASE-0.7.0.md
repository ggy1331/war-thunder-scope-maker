# War Thunder Scope Maker 0.7.0 — pre-alpha

- Ластик (E) с размером кисти 4–160 пикселей. Вырезает участки линий, дуг, фигур и рисунков. Один проход отменяется целиком через Ctrl+Z; Esc отменяет незавершённый проход.
- Изменение размера рисунка маркером в правом нижнем углу, кнопками в свойствах, числовой шириной или Ctrl + колесом. Обычное колесо увеличивает весь холст.
- Фоновая загрузка и конвертация изображений, отмена устаревших пересчётов и детализация до 2048 пикселей.
- Более компактное разбиение рисунка на геометрию и автоматическое уменьшение детализации при превышении оставшегося лимита фигур. Уменьшение явно отображается в окне импорта.
- Дополнительный режим для рисунков на неравномерно освещённом фоне.

Пройдены 79 автоматических проверок. Конвертация остаётся одноцветной; предел проекта — 20 000 экспортируемых фигур. Исходники ограничены 64 мегапикселями и 256 МБ на файл; рабочая копия — 4096 пикселями по длинной стороне. Проверка в самой игре пока не проведена.

Распакуйте архив целиком и запустите `War Thunder Scope Maker.exe`. Нужны Windows и .NET Framework 4.x.
