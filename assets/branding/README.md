# WT Scope Maker branding (0.6.2)

`scope-maker-emblem.png` is the unmodified image provided by the user for the application logo. Its aspect ratio and transparency are preserved.

`scope-maker-logo.png` (1024×1024) and `scope-maker-logo.svg` display the emblem inside a vector reticle with the caption `WT Scope Maker` underneath, on a rounded dark tile. The SVG embeds the source PNG. The application header uses the same emblem and reticle and places the caption underneath, with text matching the selected theme.

`scope-maker.ico` includes 16, 24, 32, 48, 64, 128 and 256 px variants. Regenerate the composed assets with `--write-branding <directory>`; `assets/branding/scope-maker-emblem.png` must be present next to the executable.

War Thunder Scope Maker is an unofficial project and is not affiliated with Gaijin.
