# War Thunder Scope Maker 0.6.3 — pre-alpha

Windows-приложение для создания пользовательских танковых прицелов War Thunder.

## Запуск

Скачайте `War-Thunder-Scope-Maker-0.6.3-prealpha.zip` из вложений релиза, распакуйте архив целиком и запустите `War Thunder Scope Maker.exe`. Папки `assets` и `templates` должны оставаться рядом с EXE. Установка и подключение к интернету не нужны; требуется .NET Framework 4.x.

## Возможности

- Рисование линий, окружностей, прямоугольников и треугольников, карандаш и текст.
- Импорт рисунков с преобразованием в геометрию прицела.
- 66 игровых сеток, три стартовых шаблона и 16 фонов редактора WT.
- Сохранение проектов `.wtsm`, импорт и экспорт `.blk`, отмена и повтор.
- Светлая/тёмная тема, акцентный цвет и русский/английский интерфейс.

## В этой версии

- Автопоиск папки UserSights, выбор профиля WT и запоминание папки экспорта.
- После сохранения проекта вопрос при закрытии появляется только при новых изменениях. Отмена до сохранённой версии также снимает отметку изменений.
- Новый логотип с эмблемой самолёта внутри прицела и подписью WT Scope Maker.

Пройдены 56 автоматических проверок. Проверка в самой игре пока не проведена; предпросмотр приблизительный, баллистика полностью не эмулируется. Подробные ограничения указаны в README.

Неофициальный проект, не связанный с Gaijin.
